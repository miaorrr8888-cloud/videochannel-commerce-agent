# 广告违禁词初筛基线（法条来源）

> **本文件的来源与性质**：条目依据《中华人民共和国广告法》（2021 年修正）相关条款摘录整理，
> 法律、法规文本依《著作权法》第五条不适用著作权保护，故本表可作为独立基线随包分发。
> **它不是**第三方技能 `ad-redline-guardian` 词库的拷贝，两者可以并存：
> 有该技能时优先用它（词更多），没有时用本表（保证闸门仍能工作）。
>
> 基线版本：2026-11-03。法条本身稳定，但**各平台实施细则会变**，
> 本表只做初筛，命中不等于违规成立，最终以人工复核与平台现行规则为准。

匹配规则：`命中词` 是扫描用的关键词；`依据` 说明为什么上表。
本表刻意收窄为高精度词（例如用「销量第一」而不是裸「第一」），
宁可漏检也不滥报，避免把「第一步」「最基础的用法」判成违规。

## 一、绝对化用语（《广告法》第九条第三项）

| 命中词 | 依据 |
|--------|------|
| 国家级、最高级、最佳 | 第九条第三项明令禁止的用语 |
| 最好、最优、最强、最先进、最高端 | 第九条第三项「等用语」的同类绝对化表达 |
| 最便宜、最低价、全网最低、全网最优惠 | 绝对化价格比较，无法自证 |
| 销量第一、排名第一、行业第一、全国第一、第一品牌 | 排名类断言，需可核验的第三方数据 |
| No.1、TOP1、销量冠军 | 同上的外文/变体写法 |
| 独一无二、绝无仅有、空前绝后、史无前例 | 排他性断言 |
| 顶级、顶尖、极致、至尊、王牌、巅峰 | 无标准的等级断言 |
| 万能、全能、包治、根治 | 全场景适用断言 |
| 100%有效、百分百有效、绝对有效、绝对安全 | 效果/安全的绝对化保证 |
| 永久、终身有效 | 时效性绝对化承诺 |

## 二、权威背书类（第九条第二项、第十四条）

| 命中词 | 依据 |
|--------|------|
| 驰名商标 | 第十四条：不得用于广告宣传 |
| 国家免检、国家认证 | 免检制度已取消；认证须有可查证书编号 |
| 政府指定、国家机关推荐、国家机关专供 | 第九条第二项：不得使用国家机关名义或形象 |
| 特供、专供、军供 | 明令禁止的专供类表述 |
| 央视上榜、CCTV推荐、央视展播品牌 | 须有真实合作证明，否则属虚假背书 |
| 专家推荐、院士推荐、名医推荐 | 须有真实、可核查的推荐文件 |
| 领导人同款、领导人推荐 | 第九条第二项 |

## 三、欺诈误导类（第二十八条）

| 命中词 | 依据 |
|--------|------|
| 点击领奖、全民免单、免费送 | 无真实活动的虚假承诺 |
| 仅此一天、最后一天、错过再等一年 | 虚构紧迫感；确有限时活动须真实可查 |
| 虚构原价、虚假原价、先涨后降 | 第二十八条：价格信息与实际不符 |
| 秒杀价、清仓价 | 需与真实历史成交价一致，否则属误导 |
| 图文不符、以次充好 | 第二十八条：对购买有实质性影响的虚假信息 |

## 四、功效承诺类（第十六条、第十七条、第十八条）

| 命中词 | 依据 |
|--------|------|
| 治疗、治愈、疗效、药到病除、包治百病 | 第十七条：非医疗广告不得涉及疾病治疗功能 |
| 抗癌、降血压、降血糖、替代药物 | 同上，属疾病治疗/医疗用语 |
| 无副作用、零副作用、绝对无刺激 | 安全性断言，须有依据 |
| 三天见效、七天见效、立即见效 | 效果时间承诺，第十六条禁止保证功效 |
| 减肥不反弹、彻底清除、修复受损细胞 | 效果断言 |

## 五、投资回报类（第二十五条）

| 命中词 | 依据 |
|--------|------|
| 保本、保收益、保证升值、稳赚不赔、稳赚 | 第二十五条：不得对未来收益作保证性承诺 |
| 无风险、零风险、零风险高回报 | 同上，且须提示风险 |
| 年化收益保证、必涨、包赚 | 同上 |
| 躺赚、静态收益、日入过万、月入十万 | 收益暗示，属误导性承诺 |

## 六、迷信风水类（第九条第八项）

| 命中词 | 依据 |
|--------|------|
| 转运、改运、招财、旺夫 | 第九条第八项：不得含迷信内容 |
| 辟邪、化煞、镇宅、开光 | 同上 |
| 风水宝地 | 同上 |
