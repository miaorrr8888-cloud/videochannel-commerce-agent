# 示例输出：拿模板事实直接跑闸门会怎样

这是真实运行记录（2026-11-04，Windows，Python 3.13）。
输入是**未回填的模板**，目的就是给老板看一件事：**闸门会拦住占位内容，不会放行。**

## 输入

- 运行目录：`runs/VC-Q2-001/`
- 事实文件：`runs/VC-Q2-001/PRODUCT_FACTS.json`（直接 `cp templates/PRODUCT_FACTS.template.json` 而来，字段全是空串）

## 执行命令

```bash
python scripts/channel_gates.py --run runs/VC-Q2-001 --sku VC-Q2-001 --gate all
```

## 实际输出（原样粘贴）

```text
[FAIL] GATE-0 IDENTITY_LOCK      0.000s / 1.0s
        └─ PRODUCT_FACTS.json 仍是模板占位内容：product_name 与 facts 均为空 → 禁止进入生产流程，先回填真实事实
[FAIL] GATE-1 SKU_GUARD          0.000s / 1.0s
        └─ 缺必需产物：01_research/BLOCKED_FIELDS.json
[PASS] GATE-2 COMPLIANCE         0.004s / 3.0s
[FAIL] GATE-3 AI_DISCLOSURE      0.000s / 1.0s
        └─ 缺 ai_generated_content 字段：必须声明本片是否含 AI 生成内容
[PASS] GATE-4 MEDIA_TECH         0.000s / 5.0s
[PASS] GATE-5 FRAME_EXTRACT      0.001s / 120.0s

总体：FAIL  总耗时 0.005s  → _gate/channel_gates.json
```

进程退出码：`1`（FAIL 时非 0，可直接接 CI）

## 怎么读这个结果

| 闸门 | 结果 | 含义 |
|---|---|---|
| GATE-0 身份锁 | FAIL | 事实源还是模板，**这一步没做，后面全部无意义** |
| GATE-1 SKU 守卫 | FAIL | 缺 `01_research/BLOCKED_FIELDS.json`，即没声明哪些字段是拿不到的 |
| GATE-2 合规 | PASS | 违禁词扫描无命中；空文案本来就没什么可违规的 |
| GATE-3 AI 标注 | FAIL | 没写 `ai_generated_content`，视频号要求明示是否 AI 生成 |
| GATE-4 媒体技术 | PASS | 还没成片，这一轮不校验 |
| GATE-5 抽帧 | PASS | 同上，`--video` 未给时不抽帧 |

## 回填后的正常路径

1. 把 `PRODUCT_FACTS.json` 的 `product_name`、`facts.*` 换成**核实过**的真实信息；
2. 拿不到的字段写进 `01_research/BLOCKED_FIELDS.json`，不许编；
3. 补 `ai_generated_content`（`true` / `false` 都要显式写）；
4. 再跑同一条命令，GATE-0/1/3 应转 PASS。

**这一步不做，别指望产出能发布。**
