# 视频号违禁词库（channel-guard 扩展层）

> 词库版本：2026-09-20
> 来源：《广告法》（2021修正）第九条、市场监管总局典型案例、《微信视频号运营规范》、
> 微信小店商品发布规则、视频号创作平台《短视频带货场景 AI 应用规范》（2026-08-10 生效）。
> **本词库是基础层 `ad-redline-guardian` 词库的扩展层，两者叠加使用，不是替代关系。**

匹配说明：`命中词` 为扫描关键词；`建议` 为改写方向（非唯一答案）。

---

## 0. 视频号平台特有硬红线

> 与抖音/淘宝不同，视频号对**真人身份一致性**和**AI 合成隐瞒**的判罚更重，
> 因为视频号在微信生态内，信任成本高、平台治理倾向保守。

| 命中词 | 建议改写方向 |
|--------|-------------|
| 官方、旗舰、专卖、总店、直营（非对应店铺主体时） | 删除，或改为与店铺主体一致的真实名称 |
| 微信官方、腾讯官方、视频号官方 | 删除；非官方账号使用属冒充平台 |
| 内部渠道、内部价、员工价（无据） | 删除虚构身份话术 |
| 加微信、私聊我、扫码加我、后台私信（引导站外/私域） | 删除导流话术，视频号禁站外引流 |
| 点赞抽奖、关注领奖、转发免单 | 需真实活动且报备，默认删除 |
| 清仓、甩卖、最后一批（常态化出现） | 确为真实清仓可保留，循环使用判虚构紧迫感 |

## 1. 数字人 / AI 合成隐瞒（视频号 2026-08-10 新规，最高优先级）

> 带货短视频含 AI 生成内容的，**必须主动标注**，否则限制分发；
> 标注后若 AI 生成内容与实物不符，**同样限制分发**。反复违规 → 账号整体降权、限制带货权限。

| 命中词 | 说明 |
|--------|------|
| 真人实测、我亲自试过、我本人用的、亲测（数字人/AI 口播时） | AI 口播冒充真人实测，属虚构使用体验，判定最重 |
| 我的真实使用感受（AI 口播时） | 同上，需真人真实体验方可声明 |
| 实拍、实物拍摄（画面为 AI 合成时） | 声称实拍但为 AI 生成，属虚假陈述 |
| 无美颜、无滤镜、原相机（AI 生成画面时） | 同上 |
| 素人推荐、普通宝妈推荐、路人评价（AI 合成人设时） | 虚构身份推荐 |

**注：** 判断依据不是"是否用了 AI"，而是"是否用 AI 冒充了人/真实体验"。
真人出镜口播 + AI 只做辅助剪辑 → 不属隐瞒，可正常标注后发布。

## 2. 医疗器械 / 儿童用品类（儿童身高测量仪适用）

> 若商品涉及儿童用品、测量类工具，标注精度不得宣称"医用级/诊断级"，不得暗示可替代医疗检测。

| 命中词 | 说明 |
|--------|------|
| 医用级、医疗级、诊断级、医院同款（非医疗器械） | 非医疗器械冒用医疗术语 |
| 专业测量、精准到毫米（无检定证书） | 精度宣称需计量检定证书支撑 |
| 测出孩子矮小、判断发育迟缓、预测成年身高 | 暗示医疗诊断功能，儿童类目重罚区 |
| 长高、助长、促进发育（普通测量工具） | 功效承诺，测量工具不具备该功能 |
| 替代体检、替代医院检查 | 严重违规，暗示替代医疗服务 |

## 3. 通用绝对化用语补漏（基础词库之外）

| 命中词 | 建议改写方向 |
|--------|-------------|
| 销量冠军、销量领先（无第三方数据） | 删除，或改为"XX平台XX时段销量排名（附出处）" |
| 好评如潮、零差评、无人差评 | 删除绝对化评价断言 |
| 唯一选择、没有之一 | 删除 |
| 官方认证（无认证文件） | 删除或注明真实认证机构全称 |
| 专利技术（无专利号） | 附专利号，否则删除 |
| 进口原料、进口品质（无报关/产地证明） | 需证明文件 |

## 4. 儿童 + 数据表述类（最易踩的隐性红线）

| 命中词 | 说明 |
|--------|------|
| 3秒、三秒、一秒、1秒、瞬间、秒出数、秒出结果、几秒就出 | 时间宣称需与实测一致，禁止夸大。**词库按最小可独立出现的短语切分，避免整词导致漏抓** |
| 误差为零、零误差、绝对精准、精准到毫米、精准无误 | 任何测量工具都有误差范围，精度须有计量检定证书 |
| 0.1毫米、0.5毫米、毫米级 | 精度数字属技术宣称，须可验证；无证书即违规 |
| 适用所有年龄、全年龄段、全年龄通用 | 需与产品说明书一致，禁止扩大适用范围 |
| 欧盟标准、美国标准、国际认证、欧盟认证 | 需注明标准号与认证机构 |
| 看得见、肉眼可见（身高/发育变化语境） | 暗示助长功效，测量工具不具备该功能 |
| 比医院准、比体检准、代替医院 | 暗示优于或替代医疗检测，严重违规 |

## 使用方式

```bash
# 基础层 + 扩展层叠加扫描
python scripts/check_banned.py <文本文件> \
  --words "<skills>/ad-redline-guardian/references/banned-words.md" \
         "<本技能>/references/banned-words-videochannel.md"
```

**纪律：** 词库是初筛快照，不代替人工判断。命中即拦截，误判由人工复核后加白名单，
**禁止生产 Agent 自行绕过闸门**。
